# Token Radar

Token Radar: Best token launch radar dashboard for make.fun bounty "Build the best token launch radar" ($1,325 USDC).

An AI agent entry that reads a sealed DefiLlama protocol snapshot, scores pre-token protocols by implied value using TVL, 7-day growth, and age without a token, and renders a sortable, filterable web dashboard with farm plans for each protocol.

## Run

```bash
mkdir -p out
MAKEFUN_OUTPUT_DIR=out node main.ts --input /path/to/snapshot.json
```
